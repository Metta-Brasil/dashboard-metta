## ✅ Pronto

### Infra
- Repo `Metta-Brasil/dashboard-metta` (privado) no GitHub Metta
- Next.js 16.2.6 + React 19 + Tailwind 4 + TypeScript + shadcn/ui
- Tokens visuais Metta (amarelo #FFBE18 primary, azul noite foreground, fundo branco, radius 12px)
- Fonte Inter (visual SaaS moderno tipo Linear/Vercel)
- Vercel deploy + alias prod apontando pra deploy mais recente
- Cron diário `/api/cron` às 11h BRT (Hobby plan limita 1×/dia)
- Endpoint manual `/api/revalidate` (header `x-revalidate-secret`)
- Sem login (página de login removida conforme combinado)

### Dados (Sheets API)
- Service Account `dashboard-metta-readerdashboar@dashboard-metta.iam.gserviceaccount.com` com acesso à planilha
- 5 abas integradas: `fb_todos`, `leads`, `sdr`, `vendas`, `Metas`, **`ads links`** (também)
- Schemas Zod tolerantes em `src/lib/sheets/schemas.ts` (helpers `zCurrency`, `zDate`, `zInt`, `zString`)
- Cache Components: `use cache` + `cacheLife({revalidate:600, expire:3600})` + `cacheTag("sheets-data")`
- batchGet via `readAllSheets([...])` — 1 request HTTP pra N abas

### Camada Calc (puro TypeScript, sem React)
Todas as 7 funções implementam **todos** os campos previstos no wireframe + PRD:

| Calc | Output | Fonte |
|---|---|---|
| `calcVisaoGeral` | 19 KPIs, série diária, funil 7 etapas, custo/etapa, distribuição por funil, tabela diária 13 colunas | PRD §5.2.1 |
| `calcTrafego` | 12 KPIs, série combo, MQL/CMQL por funil (5 fixos), funil 5 etapas, resumo 6 métricas, ranking campanha/adset | PRD §5.2.2 |
| `calcSdr` | 7 KPIs, funil SDR 5 etapas, heatmap 7×24, performance por SDR (9 cols) | PRD §5.2.3 |
| `calcCloser` | 9 KPIs (ROAS + ciclo médio), donut receita/funil, evolução 12m com meta, vendas do período, performance por Closer (11 cols) | PRD §5.2.4 |
| `calcAnuncios` | top CPL/CMQL/Vendas, galeria 12 cards com thumbnail+IG, ranking 15 colunas | PRD §5.2.5 + aba `ads links` |
| `calcOrigem` | 7 dimensões dedicadas (porUtmSource, porUtmMedium, porUtmCampaign, porQualificacao, porCargo, porFaturamento, porSegmento) | wireframe p8 |
| `calcMetas` | Hero faturamento, tabela funil meta×real (7 linhas), 4 cards taxa, pacing chart, pacing necessário, histórico mensal | wireframe p6 |

- 7 páginas com **todos** os blocos do wireframe representados (visual cru — tabelas básicas, sem Recharts ainda)

- Smoke test final: todas as 7 rotas → HTTP 200, sem erros nos logs
